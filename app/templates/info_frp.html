Nuestro Objetivo

IGNIS AI emplea como modelo de Machine Learning, XGBoost Regressor. Este modelo predice el FRP, que es la energía liberada por un incendio. Entrena el modelo con datos de incendios de Europa y Norte de África desde 2022 a 2026.

Fuentes de Datos y Enlaces de APIs y Webs

🛰️
NASA FIRMS - Archivos CSV para la obtención de incendios
☁️
OpenMeteo - API para datos meteorológicos
🌍
Google Earth Engine - Obtención de índices de vegetación (NDVI, NDWI) y pendiente del terreno
🗺️
Copernicus Land Cover - Mapa rasterizado para la obtención del tipo de vegetación
🗺️
Europa EU - Mapa rasterizado para la obtención de la calidad del suelo
🌡️
Nasa - API para obtención de la temperatura del suelo
